# Arduino Projects

A collection of hands-on Arduino projects covering sensors, displays, motors,
and communication protocols. Built as part of embedded systems development.

---

## Projects

| Folder | Description | Hardware |
|---|---|---|
| 01_blink | Basic LED blink | Arduino, LED |
| 02_ultrasonic_sensor | Distance measurement with HC-SR04 | HC-SR04, Arduino |
| 03_lcd_display | Text output on 16x2 LCD via I2C | LCD1602, Arduino |
| 04_temperature_sensor | Temperature and humidity reading | DHT11, Arduino |
| 05_servo_motor | Servo motor angle control | SG90, Arduino |
| 06_ir_remote | IR remote receiver and decoder | IR receiver, Arduino |
| 07_relay_control | Controlling loads via relay | Relay module, Arduino |
| 08_serial_communication | UART data exchange between devices | Arduino |

---

## Hardware Used

- Arduino Uno / Nano / Mega
- Sensors: DHT11/DHT22, HC-SR04, IR receiver
- Actuators: LEDs, SG90 servo, relay modules, buzzers
- Displays: 16x2 LCD (I2C), OLED SSD1306

---

## Skills Demonstrated

- GPIO control (digital and analog)
- I2C and UART communication protocols
- PWM for motor and LED control
- Sensor data reading and processing
- Library integration in Arduino IDE
- Serial monitor debugging

---

## Platform

- Arduino IDE
- Language: C++ (Arduino framework)
- Libraries: Servo, Wire, LiquidCrystal_I2C, DHT, IRremote

---

## Getting Started

1. Open the project folder in Arduino IDE
2. Install required libraries via Library Manager
3. Select your Arduino board and COM port
4. Upload and open Serial Monitor at 9600 baud
